Airlock — System Architecture

Request → Scan → Gate → Release

Every package a build depends on is resolved against a canonical store, scanned by a horizontally-scaled worker pool behind RabbitMQ, and — with one deliberate exception — always signed off by a human before it's trusted. A second, independent loop keeps released packages under ongoing watch after they ship.
